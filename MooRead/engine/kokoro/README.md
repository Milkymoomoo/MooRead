# Bundled neural voice (Kokoro-82M)

These two files are the desktop voice engine. They are **not** committed here.
Download them using the links in [VOICE_MODELS.md](../../../VOICE_MODELS.md).

| File | What it is |
| --- | --- |
| `kokoro-v1.0.int8.onnx` | Quantized Kokoro-82M acoustic model. |
| `voices-v1.0.bin` | 54 speaker style vectors for kokoro-onnx (numpy). |

Official zip: https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.0
